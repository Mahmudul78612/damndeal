# DamnDeal Delivery — Android App Build Guide

## 📱 Two Ways to Install on Android

---

### Option 1: PWA (Progressive Web App) — Easiest!

**No build needed.** Just deploy the web app and install from Chrome on any Android phone.

#### Steps:
1. **Deploy** the `deliveryapp/` folder to any web server (Nginx, Apache, Netlify, Vercel, etc.)
2. On Android phone, open the URL in **Chrome**
3. Chrome will show **"Add to Home Screen"** banner automatically
4. Tap it → App installs with icon, splash screen, no browser bar — feels like a real app!

#### Requirements:
- Must be served over **HTTPS** (service worker requires it)
- For local testing: `npx serve .` (use on same WiFi network)

---

### Option 2: Capacitor APK — Play Store Ready!

Build an actual `.apk` / `.aab` file for Android.

#### Prerequisites:
- **Node.js** 18+ 
- **Java JDK 17** (for Android build)
- **Android Studio** (for SDK & emulator)
  - Download: https://developer.android.com/studio
  - After installing, open SDK Manager → install Android SDK 34

#### Build Steps:

```bash
# 1. Go to delivery app folder
cd "A:\damndeal project\deliveryapp"

# 2. Install dependencies
npm install

# 3. Initialize Capacitor (already configured via capacitor.config.json)
# If first time:
npx cap add android

# 4. Sync web files to Android project
npx cap sync android

# 5. Open in Android Studio (to build APK)
npx cap open android
```

#### In Android Studio:
1. Wait for Gradle sync to finish
2. **Build → Build Bundle(s) / APK(s) → Build APK(s)**
3. APK will be at: `android/app/build/outputs/apk/debug/app-debug.apk`
4. Transfer APK to phone → Install → Done! 🎉

#### OR build from command line:
```bash
cd android
.\gradlew assembleDebug
# APK at: android/app/build/outputs/apk/debug/app-debug.apk
```

#### For Release (Play Store):
```bash
cd android
.\gradlew bundleRelease
# AAB at: android/app/build/outputs/bundle/release/app-release.aab
```
(You'll need to configure signing key for release builds)

### 🎨 App Icons (Production)

Current icons are SVG placeholders. For Play Store, you need proper PNG icons:

1. Go to https://realfavicongenerator.net
2. Upload `assets/icons/icon.svg`
3. Download all sizes → replace files in `assets/icons/`
4. For Android adaptive icons, use Android Studio's **Image Asset Studio**:
   - Right-click `res` → New → Image Asset

### ⚙️ Configuration

Edit `assets/js/config.js` to change API URL:
```js
const CONFIG = {
  API_BASE: 'https://your-server.com/api',  // Change this!
  ...
};
```

For Capacitor, also update `capacitor.config.json` if using a live server:
```json
{
  "server": {
    "url": "https://your-server.com",
    "cleartext": true
  }
}
```
